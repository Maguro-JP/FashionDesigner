FashionDesigner mesh core

JSON形状から閉じた三角形メッシュを作り、OBJ/GLBへ書き出すPython標準ライブラリのみのコアです。現在は単一輪郭の押し出しまでを対象とし、縫製済み衣服や人体フィットは生成しません。

  1. JSON形状データを用意する
  2. export_obj(points, depth) または export_glb(points, depth) を呼び出す
  3. 出力を3Dソフトで開き、軸・尺度・面の向きを確認する

ローカル検証: python -m unittest -v test_mesh_core.py

詳細は 設計と制限 を参照。
